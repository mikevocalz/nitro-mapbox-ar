# Reference app accessibility review

WCAG 2.1 AA, with a 48 dp minimum target for Quest look-and-pinch. Screens: Map, Navigate, AR, Table, Agent, plus the shared header and tab bar.

The review was done from source. No screen reader, switch or device session was run (no simulator was booted for this pass). Line references point at the code before the fixes, commit `c7e6ba7`; every finding below was fixed in `323d1d4` unless its status says otherwise.

**Verdict:** accessibility risks fixed in code; behaviour on a device still needs a screen-reader pass (see the end).

## Needs verification on a device

None of these block the code fixes above, and none can be confirmed from source:

- TalkBack and VoiceOver read the tab row as a tab list with the selected tab announced.
- iOS announcements from `StatusText` do not double up with VoiceOver reading the focused button.
- The Quest panel's "Enter immersive view" button is reachable with look-and-pinch and controller ray; the 48 dp minimum is in code, the hit area in a panel is not measured.
- The visionOS window: the AR tab is hidden there (`App.tsx` checks `isVisionOS()`), and the Table tab's map shows the unavailable message.
- Dynamic Type / font scale at 200% on the Agent results list.
